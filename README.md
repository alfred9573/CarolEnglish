# CarolEnglish

Planes de clase, ejercicios y evaluaciones para practicar inglés. Cada clase vive en su propia carpeta dentro de `clases/` y trae dos archivos:

- **`plan.md`**: la guía completa para quien da la clase (tiempos, instrucciones, respuestas y rúbrica).
- **`alumno.md`**: solo los ejercicios, sin respuestas, para mostrar en pantalla o imprimir.
- **`interactiva.html`**: versión interactiva para contestar en el celular; califica sola y da el nivel al final.

## Cómo agregar una clase nueva

1. Crea una carpeta `clases/NN-tema-nivel/` (por ejemplo `02-pasados-b1`).
2. Agrega su `plan.md` y su `alumno.md`.
3. Súmala a la tabla de arriba.
